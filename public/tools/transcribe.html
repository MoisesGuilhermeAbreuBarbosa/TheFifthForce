Transcribe an English audio file on your device using a free Whisper model. Import existing SRT or VTT captions when available.

Your selected audio stays in this browser. Model files download from Hugging Face on first use; that provider receives normal download requests. No paid API or automatic publication is used. The small model can mishear names, equations and numbers: verify against the recording.

Audio: up to 100 MB and 20 minutes per clip. Split longer recordings. Browser codec support varies. A YouTube URL alone is not an audio file.
